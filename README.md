# Boykotify

Boykotify; Spotify listelerinizdeki terör sempatizanlarını ve Türk düşmanlarını ayıklayan bir milli şuur projesidir. Atatürk'ün izinde, vatanın birliğine kastedenlere dijital alanda geçit vermiyoruz. Sanat kisvesi altında ihaneti besleyenleri tespit edin, listenizden silin! Türk istiklalini ve Cumhuriyetini korumak için her alanda uyanığız. 

Ne Mutlu Türküm Diyene!

## Özellikler
- **Hızlı Tarama:** Spotify çalma listelerindeki boykotlu ve vatansever sanatçıları anlık tespit eder.
- **İnteraktif Filtreleme:** Skor tablosu üzerinden kategorilere göre şarkıları anında süzün.
- **Tek Tıkla Temizlik:** Boykotlu şarkıları "S*KTİR ET!" aksiyonuyla veya toplu olarak listenizden atın.
- **Veri Kalıcılığı:** Sayfa yenilense bile taranan sonuçlarınız korunur.
- **Techno-Minimalist Tasarım:** Göz yormayan, aksiyon odaklı ve modern bir kullanıcı arayüzü.
- **Yırtıcı Animasyonlar:** Şarkı silme eylemine güç katan özel geçiş efektleri.

Daha fazla detay için [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md) dosyasını inceleyebilirsiniz.

## Teknoloji Yığını
- **Frontend:** React + Vite
- **Database:** Supabase
- **API:** Spotify Web API

## Kurulum
1. `npm install`
2. `.env` dosyasını oluşturun ve gerekli API anahtarlarını ekleyin.
3. `npm run dev` ile yerelde çalıştırın.
